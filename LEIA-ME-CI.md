# Macro02 R5 — laboratório GitHub Actions

Não é migration aprovada. As fases A e B são os mesmos bytes de R5. Executa os testes dirigidos duas vezes, com PostgreSQL **17.6** oficial: fixture sintética original e overlay de catálogo produtivo observado. O overlay reproduz colunas relevantes, constraints, RLS owner PUBLIC, policies retiradas, FKs de escopo, referência de supply e a policy Stability em persons. Não é cópia integral do schema real nem da plataforma Supabase; não inclui todas as policies de compartilhamento, defaults, tabelas e extensões. Nenhum dado clínico real, nenhuma credencial Supabase, nenhum DDL de produção.

Workflow dedicado em branch SQL-only órfã `vault-lab/macro02-pg17-r5-*`, sem código da aplicação, sem main, sem merge e sem APK. Configuração Vercel desabilita deployment da branch; se o provedor externo ignorar essa configuração não há aplicativo a compilar. GitHub Actions usa minutos do plano existente; não criar recurso pago adicional. Requer autorização de push e workflows no repositório. O pacote pode ser entregue ao Guardian desde já; os logs são anexados como artefato mesmo quando o teste falha. Não confundir o job preparado com um job executado. Após GO específico, preflight e backup verificado, usar apply_migration pelo plugin. Ativação permanece separada, sem rollback destrutivo de fatos.
